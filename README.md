# FlowPilot 节点式数据工作流编辑器

基于 React、TypeScript、Vite、React Flow、Ant Design、Zustand、Immer 与 React Router。

## 功能

- 从节点库拖拽数据源、变换、过滤、聚合、双流关联和输出节点。
- 连线时校验输入/输出端口类型，实时拒绝类型冲突和环形依赖。
- 支持框选、复制粘贴、删除、撤销重做、缩略图与依赖层级自动布局。
- 流程保存为 JSON 并可重新导入。

## 执行模型

- **不可变快照**：点击执行时把当前画布冻结为流程快照（节点配置、连接关系、结果指纹），运行中的画布改动不会影响本次执行；内容未变时复用已有快照版本。
- **运行批次**：每次执行生成一个批次记录，同一批次重复提交不会生成第二份；同层节点并发执行。
- **失败恢复**：节点失败后，已成功结果保留在结果缓存中，未开始的节点记为取消，修复后可直接续跑。
- **增量重算**：节点、连线或上游结果变化时，受影响下游的结果指纹立即失效；下次执行只重算这些部分，其余结果继续复用。
- **断点续跑**：工作区（含快照、批次、结果缓存）持久化到本地，刷新或写入中断后从成功结果继续。
- **版本兼容**：旧版（v1）流程 JSON 打开时自动升级，补建首版快照并把已有成功结果迁入缓存。
